# Ecommerce_Sales_Profit_Analysis_excel

A hands-on Excel project where I analyzed an e-commerce sales dataset to practice data analysis and business problem-solving.

What I worked on
- Basic sales & profit analysis
- Category and payment-mode analysis
- Profit margins
- `IF`, `SUMIF`, `SUMIFS`, `COUNTIFS`, `AVERAGEIFS`
- `XLOOKUP` and basic data cleaning
- PivotTables
- Topics from basic to advanced

Key Numbers
- Total Sales ₹437,771
- Total Profit ₹36,963
- Transactions 1,500
- Profit Margin 8.44%

Tools
Microsoft Excel

This is one of my first hands-on projects while building my Data Analytics portfolio.
